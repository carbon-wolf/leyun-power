# leyun_power —— 乐云一卡通水电费巡检提醒

定时查宿舍水电余额，低于阈值自动推到 QQ 群 / 私聊。

数据来自乐云一卡通微信端（`wx.leyunykt.com`）。鉴权用**手机号 + 登录密码**自动登录，
不依赖微信、不需要每天抓包；查询和推送全程在服务器上跑，手机不用开着。

这是 [ncqqpy](https://github.com/Green1423/ncqqpy) 的插件：框架扫描 `plugin_dir`
（默认 `./plugins`）下的子目录加载，把整个目录放进 `plugins/` 即可。

## 安装

```bash
cd /path/to/ncqqpy
git clone <本仓库地址> plugins/leyun_power
pip install -r plugins/leyun_power/requirements.txt   # cryptography + aiohttp

# 然后 QQ 私聊机器人：
/reload leyun_power
```

## 首次上手

```
① 填 rooms（房间编号因学校/楼栋而异，见「房间怎么填」），/reload leyun_power
② 私聊机器人：/水电 登录 <手机号> <登录密码>
   如果回「需要短信校验」→ /水电 验证 → 收到码 → /水电 验证 <6位码>
③ 把机器人拉进宿舍群
④ 群里发一次：/水电 绑定
```

之后不用管了：每 30 分钟查一次电费 + 水费，低于阈值自动推到那个群，同一项 6 小时内
不重复刷屏。

> **登录**和**绑群**是两件事：`/水电 登录` 决定用谁的身份查（仅私聊，密码不留痕），
> `/水电 绑定` 决定提醒发到哪个群（群里发即绑当前群，也可以私聊 `/水电 绑定 <群号>`）。
> `/水电 验证` 同样只在私聊用，校验码不会进群。

## 命令

只注册**一个入口命令组** `leyun`（别名 `水电`、`sd`），下挂少量子命令 —— 不给每个
设置项各开一条子命令，避免把 bot 的顶层命令空间塞满：

| 命令 | 作用域 | 说明 |
|---|---|---|
| `/leyun` / `/水电` / `/sd` | — | 裸调由框架重定向到 `/help leyun` |
| `/leyun login <手机号> <登录密码>` | 仅私聊 | 登录一卡通账号，成功后立刻返回当前余额 |
| `/leyun bind [群号]` | 群聊 / 私聊 | 把余额提醒绑到群：群里留空=本群，私聊要带群号 |
| `/leyun verify [校验码]` | 仅私聊 | 新设备登录的短信校验：不带码=发送，带码=提交 |
| `/leyun query` | 所有场景 | 手动查一次余额 |
| `/leyun config [子项 ...]` | — | **统一设置入口**，见下表 |
| `/leyun scope [子项 ...]` | 仅私聊·仅超管 | **服务范围白名单**（谁能用），见「服务范围」 |

`/水电 绑定` 会把该群同时写进服务范围（`binding.groups`），所以绑完就能在群里直接
查询 / 设置，不用再手工开白名单。要换群就在新群里再发一次，取消用
`/水电 设置 移群 <群号>`。

`config` 的子项（空格分隔，全角半角都认）：

| 写法 | 效果 |
|---|---|
| `/水电 设置` | 显示当前配置面板（账号、阈值、推送目标、间隔、冷却） |
| `/水电 设置 电 10` | 电费低于 10 元提醒 |
| `/水电 设置 水 5` | 水费低于 5 元提醒 |
| `/水电 设置 开` / `关` | 开关自动巡检 |
| `/水电 设置 本群` | 等价于在群里发 `/水电 绑定`（老写法，保留兼容） |
| `/水电 设置 群 100200300` | 等价于 `/水电 绑定 100200300` |
| `/水电 设置 私聊 10001` | 额外私聊提醒某个 QQ |
| `/水电 设置 移群 100200300` | 移出提醒群（`移群 本群` 移当前群） |
| `/水电 设置 移私聊 10001` | 移出私聊提醒 |
| `/水电 设置 间隔 30` | 巡检间隔 30 分钟（1-1440） |
| `/水电 设置 冷却 6` | 同一项重复提醒的冷却 6 小时 |
| `/水电 设置 模板 <文案>` | **自定义余额不足提醒的文案**（见下节） |
| `/水电 设置 模板` | 查看当前文案 + 可用变量表 |
| `/水电 设置 模板 默认` | 恢复内置默认文案 |
| `/水电 设置 失败模板 <文案>` | 自定义「查询失败」提醒的文案 |
| `/水电 设置 预览` | 用实时余额（未登录则示例数据）渲染一遍看效果 |

## 房间怎么填

房间编号（`input1~input4`）是学校自己的层级，插件没法猜，需要从一次抓包里抄。

1. 在微信里打开乐云一卡通的「电费充值」，选到你的房间，随便点一下查询
2. 抓包里找 `POST .../DispApiServer/YKTGetPayProj` 这条请求，把请求 JSON 里的
   `pay_proj_type` 和 `input1`~`input4` 抄出来
3. 填进 `config.json` → `plugins.leyun_power.rooms`，电费、水费各写一条：

```json
"rooms": [
  {
    "label": "1号楼203 电费",
    "pay_proj_type": 323,
    "input1": {"id": "校区ID", "name": "校区名"},
    "input2": {"id": "楼栋ID", "name": "楼栋名"},
    "input3": {"id": "楼层ID", "name": "楼层名"},
    "input4": {"id": "房间ID", "name": "房间名"}
  },
  {
    "label": "1号楼203 水费",
    "pay_proj_type": 322,
    "input1": {"id": "校区ID", "name": "校区名"},
    "input2": {"id": "楼栋ID", "name": "楼栋名"},
    "input3": {"id": "楼层ID", "name": "楼层名"},
    "input4": {"id": "房间ID", "name": "房间名"}
  }
]
```

`pay_proj_type`：`323` = 电费，`322` = 水费（平台对接的是新开普水电控）。
`name` 只用于显示，`id` 才是查询用的；改完 `/reload leyun_power` 生效。

## 短信校验（9006）

乐云一卡通对「没见过的设备」要求一次短信校验，否则登录会被拒（返回码 `9006`，
文案是「系统检测到您更换了手机或者清理了内存，需校验是本人操作」）。

插件已经接管这一步，按提示走就行：

```
/水电 验证            → 校验码发到你绑定的手机（默认 120 秒有效）
/水电 验证 123456     → 提交，成功后立刻查一次余额
```

几点说明：

- 校验码**只活一次**，插件不把它写进配置（留在 `config.json` 里等于留痕）；
- 校验一次以后，同一账号再登录就免验证了 —— 换服务器 IP、重装插件都可能再触发一次；
- 巡检发现卡在校验时，会推送「在私聊里发 /水电 验证」而不是含糊的「查询失败」；
- 不要 1 分钟内重复发码，平台会拦（提示「发送太频繁」属正常，等一会儿再来）。

## 服务范围：谁能用（`/leyun scope`）

跟「推给谁」（`push_groups` / `push_users`）是**两层**：推送目标只决定提醒发给谁，
不决定谁能发命令。谁能用由 `binding` 白名单决定，口径与框架的
[`napcat.scope`](https://github.com/Green1423/ncqqpy/blob/main/docs/plugin-dev/20-scope.md)
一致。

| 写法 | 效果 |
|---|---|
| `/水电 范围` | 查看当前名单（群 / 人） |
| `/水电 范围 加群 100200300` | 开通该群：群聊 + **该群成员的小窗**都能用 |
| `/水电 范围 减群 100200300` | 关掉该群 |
| `/水电 范围 加人 10001` | 开通该 QQ 的**直接私聊** |
| `/水电 范围 减人 10001` | 关掉该 QQ 的私聊 |

四条规矩：

- **空 = 谁都不用**：名单为空时群聊/私聊一律静默（连 `/help` 里都看不到本插件），
  不拿框架的 `bound_groups`（「机器人监听哪些群」）兜底；
  例外是「开通动作」：`/水电 登录`、`/水电 验证`、`/水电 绑定` 不受名单限制，
  否则新装机谁都登不进来、也绑不了第一个群；
- **分通道判**：群聊与群小窗按**来源群**，直接私聊按 **QQ**，互不代替；
- **超管恒可用**：改名单的命令只在私聊由超管执行，不豁免会出现「名单配错 → 谁都改不了」；
- **升级不跳变**：老部署第一次补出 `binding` 时，会把 `owner_users` 带进私聊名单，
  之后只认名单（删掉不会被加回来）。

> 管理员（`owner_users`）能改阈值/推送，但**不自动拥有**服务范围豁免；
> 开群/开人要么超管发 `/水电 范围 …`，要么在群里发一次 `/水电 绑定`，
> 要么手改 `config.json` 的 `binding`。

## 提醒文案（可自定义）

默认文案：

```text
🔔 水电余额不足

1号楼203 — 宿舍电费
剩余 3.50 度 · 余额 1.86 元 · 单价 0.53 元/度
⚠️ 已低于提醒阈值 10.00 元，记得充值
```

想换就发一条命令，用占位符拼：

```text
/水电 设置 模板 ⚡{房间}{类型}只剩 {余额} 元\n阈值 {阈值} 元，快去充
```

推送出来就是：

```text
⚡1号楼203电费只剩 1.86 元
阈值 10.00 元，快去充
```

可用占位符（发 `/水电 设置 模板` 也能看到这份表）：

| 占位符 | 含义 | 占位符 | 含义 |
|---|---|---|---|
| `{房间}` | 房间名（`rooms[].label`） | `{余额}` | 剩余金额（元） |
| `{类型}` | 电费 / 水费 | `{单价}` | 元/度 或 元/吨 |
| `{项目}` | 平台返回的缴费项目名 | `{阈值}` | 当前提醒阈值（元） |
| `{剩余}` | 剩余量（两位小数） | `{时间}` | 月-日 时:分 |
| `{单位}` | 度 / 吨 | | |

### 提醒里 @ 人

模板里写 `{@…}` 就会变成真的 @（消息段，不是一段文字）：

| 写法 | 效果 |
|---|---|
| `{@全体成员}` 或 `{@全体}` / `{@all}` | @全体成员 |
| `{@123456789}` 或 `{at:123456789}` | @指定 QQ（5-12 位数字） |

例子：

```text
/水电 设置 模板 {@全体成员}\n⚡{房间}只剩 {余额} 元，谁在宿舍快去充
```

群里推出来是「@全体成员 + 换行 + ⚡1号楼203只剩 1.86 元…」，@ 会正常变成蓝色提醒。

三条注意事项：

- **只对群生效**：私聊推送会自动去掉 @（私聊里 at 段没有意义），文字内容照旧；
- **@全体 需要机器人是群管理员**：没有权限时 NapCat 会整条发失败，插件检测到就
  **自动补发一条纯文本**（内容不丢，只是没 @），日志里会记一条 warning；
- **别每轮都 @全体**：QQ 本身对 @全体 有频率限制，建议配合 `冷却` 用，或者日常用
  `{@某个QQ}` 只戳负责充钱的那个人。

几个约定：

- 换行写 `\n`（QQ 里没法真敲回车），保存时会自动转成换行
- 全角 `｛余额｝` 也认，手机输入法不用切
- 变量名拼错会被拒并列出可用变量，不会静默推一条空的
- 上限 500 字；`/水电 设置 模板 默认` 随时能退回内置文案
- 查询失败的提醒另有一套 `失败模板`，变量是 `{错误}` / `{提示}` / `{时间}`
- 也可以直接改 `config.json` 的 `remind_template` / `error_template`（同样支持占位符）

## 配置

插件构造期会把**全部**配置项写进 `config.json` 的 `plugins.leyun_power` 段（只补缺键、
不覆盖已有值、嵌套段逐键补、幂等），所以打开配置文件就能看到所有可改项：

```json
{
  "enabled": true,
  "base_url": "http://wx.leyunykt.com",
  "http_timeout": 15,
  "session": {
    "api_id": "…",
    "access_token": "…",
    "open_id": "123"
  },
  "account": {"tel": "", "password": ""},
  "owner_users": [],
  "threshold": {"322": 5.0, "323": 10.0},
  "rooms": [],
  "check_interval": 1800,
  "remind_cooldown_hours": 6,
  "remind_template": "🔔 水电余额不足\n\n{房间} — {项目}\n剩余 {剩余} {单位} · 余额 {余额} 元 · 单价 {单价} 元/{单位}\n⚠️ 已低于提醒阈值 {阈值} 元，记得充值",
  "error_template": "⚠️ 水电查询失败\n{提示}\n{错误}",
  "push_groups": [],
  "push_users": [],
  "binding": {"groups": [], "users": []}
}
```

- `account`：`/leyun login` 写入；也可以手工预置。密码是**明文**，这个文件别提交到公开仓库。
- `session`：平台应用级凭据，内置于 `api.py`，一般不用动。查询报「鉴权失败」时才需要
  更新（见「免维护说明」）。
- `owner_users`：能改设置、能重新登录的 QQ。留空 = 第一次 `/leyun login` 的人自动认领；
  想锁死就先在配置里填上自己。
- `binding`：**服务范围白名单**（谁能用命令）。空 = 谁都不用，超管豁免。
  例外：`login` / `verify` / `bind` 是「开通」动作，不受这道闸门限制。
- `threshold`：键是 `pay_proj_type`，`322`=水费、`323`=电费。
- `rooms`：见「房间怎么填」。
- `check_interval`：秒。定时器每 60 秒醒一次，到点才真巡检，所以改这个值立刻生效。
- `remind_template` / `error_template`：推送文案模板，留空则用内置默认。
- 运行期状态（`user_id` 缓存、上次巡检 / 提醒时间）落在 `data/state.json`，不进配置。

## 权限

两层，互不代替：

- **服务范围（能不能用）**：`binding` 白名单。名单外的群/人发命令**静默**，
  `/help` 里也看不到本插件；超管恒可用。
- **插件权限（能改什么）**：
  - `login` / `verify` 仅私聊（密码、校验码不进群），且 `login` 受 `owner_users` 限制；
  - `bind` 群聊 / 私聊都能发（群里留空=当前群），受 `owner_users` 限制，
    成功后自动把该群写进服务范围；
  - `config` 任意场景但校验 `owner_users`，群里只有管理员能改；
  - `scope` 仅私聊·仅超管（框架的 `permission="superuser"`）；
  - `query` 不限权限等级 —— 但**仍要过服务范围**（开通的群里室友都能看余额）。

## 免维护说明

`access_token` 是**应用级共享令牌**（全校共用一个，前端 JS 里可见，不随微信登录态
过期），`api_state` 与 `ltc_api_token` cookie 实测非必需。所以长期凭据只有账号密码
和「这台设备已被校验信任」这个标记。

登录态失效时会自动重登一次再查（`query_all()` 里做的）；卡在短信校验时会推送提示，
发 `/水电 验证` 即可。万一平台轮换了 `access_token`，查询会报鉴权失败 —— 从新版前端
JS 里取一次填进 `session.access_token` 即可。

```text

├── __init__.py        # 只做入口：from .plugin import ... + PLUGIN

├── content.py         # 提醒文案：默认文案 / 占位符渲染 / @ 分段 / 变量表
├── api.py             # 乐云协议（报文封装 / 签名 / 解码）+ 客户端 + 短信校验
├── store.py           # data/state.json
├── commands/
│   ├── query.py       # /leyun query 与排版（巡检复用）
│   ├── setup.py       # /leyun login + /leyun bind + /leyun config + /leyun scope
│   └── verify.py      # /leyun verify（9006 短信校验）
├── jobs/
│   └── patrol.py      # 巡检与阈值判断
├── tests/             # 离线测试（不需要真 QQ，也不联网）
├── data/              # 运行时数据（不进仓库）
├── requirements.txt
└── README.md
```

## 测试

```bash
# 逻辑：命令清单、设置写回、校验流程、巡检与冷却、文案渲染（不联网）
python tests/test_logic.py

# @ 分段：验证 {@全体成员} 真的变成 [CQ:at,qq=all]
python tests/test_at.py
```

两套都用框架真实的 `napcat.message` / `napcat.scope` / `napcat.command`，只把
`PluginBase` 换成轻量桩，所以 at 段、Schema 校验都是真跑的。

找不到框架时设 `NCQQPY_HOME=/path/to/ncqqpy`。想跑真实登录（会用到你的账号）：

```bash
LEYUN_ROOMS='[{"label":"测试","pay_proj_type":323,"input4":{"id":"房间ID"}}]' \
  python tests/test_logic.py --live <手机号> <密码>
```

协议层另有一套用真实抓包验证的回归测试（26 条响应，含 chunked + gzip 大响应），
因为里面含个人会话数据，没有随仓库发布。

## 隐私与免责

- 插件只查询**你自己账号绑定**的房间数据，不做任何写操作（不缴费、不改密码）；
- 账号密码存在**本机** `config.json`，请勿把该文件提交到任何仓库；
- `data/`、`config.json`、`.ncqqpy-plugin.json` 已在 `.gitignore` 里；
- 这是非官方插件，与乐云一卡通 / 新开普无关；接口由前端逆向得出，平台改动可能导致
  失效。请自行评估使用风险，遵守学校与平台的使用规定。
